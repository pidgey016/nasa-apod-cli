🔭 nasa-apod CLI

一条命令，获取 NASA 每日天文图片（APOD）的链接。单文件二进制，下载即用，支持 macOS / Linux / Windows。

下载最新版 GitHub 仓库

安装

# macOS (Apple Silicon) 示例，latest 直链始终指向最新 Release
curl -L … | tar xz
sudo mv nasa-apod /usr/local/bin/

其他平台请在 Releases 页选择对应压缩包（darwin / linux / windows × amd64 / arm64）。

使用

$ nasa-apod
NASA Astronomy Picture of the Day (2026-11-19)
Title: The Horsehead and Flame Nebulas
Link:  https://assets.science.nasa.gov/dynamicimage/assets/science/cds/apod/apod/2026/november/Horsehead_Nebula_Killion.jpg

# 指定日期
$ nasa-apod --date 2026-11-19

# 直接在浏览器中打开图片
$ nasa-apod --open

# 查看版本
$ nasa-apod --version

发布方式

平台架构产物
macOSarm64 / amd64.tar.gz
Linuxamd64 / arm64.tar.gz
Windowsamd64.zip

推送 v* tag 后由 GitHub Actions 自动交叉编译并发布到 Releases。

说明

数据来自官方 science.nasa.gov APOD 接口（APOD 于 2026-11 从 apod.nasa.gov 迁移而来），无需 API key、无限流。当天图片尚未发布时返回 404，可用 --date 指定日期。图片版权归 NASA 及作者所有。
